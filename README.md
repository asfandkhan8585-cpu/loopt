# Loopt

A React + Vite + Tailwind UI for monitoring simple fund transactions.

## Quick start

```bash
npm install
npm run dev     # runs locally
npm run build   # build for production (dist)
npm run deploy  # deploy to GitHub Pages (requires gh-pages)
```

After deploying, the site will be available at:
https://asfandkhan8585-cpu.github.io/loopt
